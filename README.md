# Sonsuz Devlet Dairesi Bekleme Simülatörü

## Giriş: Medeniyetin Zirvesi

Bu repository, insanlık tarihinin en büyük sorunlarından biri olan **bürokratik bekleme** sorununu çözmek için tasarlanmış devrim niteliğinde bir yazılımdır. Artık sıra beklemek istemeyen herkes, evinin konforunda sonsuza kadar bekleyebilir.

### Özellikler
- Gerçekçi bahane üretimi
- Sonsuz döngü (gerçek hayatla %100 uyumlu)
- Rastgele süre uzatma
- Memur molası simülasyonu
- Vergi iadesi gelmeme garantisi

### Nasıl Çalıştırılır?
```bash
python3 bekleme_simulatoru.py
```

Çıkmak isterseniz Ctrl+C yapın. Ama unutmayın, gerçek hayatta çıkış yok.

### Neden Bu Proje?
Çünkü hayat kısa, sıralar uzun. Bu simülatör sayesinde:
- Zamanınızı daha verimli boşa harcayabilirsiniz
- Bürokrasiye hazırlanabilirsiniz
- Hayatın gerçeklerini öğrenebilirsiniz

### Lisans
Bu yazılım ücretsizdir. Tıpkı devlet hizmetleri gibi. (Ama aslında ücretlidir, sadece siz fark etmezsiniz.)

### Katkıda Bulunma
Pull request açabilirsiniz ama onay süreci 6-18 ay sürebilir. Lütfen sabırlı olun.
